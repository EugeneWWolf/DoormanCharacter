# Doorman для Risk of Rain 2

## Запуск через r2modman

1. Установи ExtraSkillSlots от KingEnderBrine в выбранный профиль. Для сборки использовалась версия 1.6.5.
2. Если в профиле уже есть старая сборка этого мода, отключи её или убери её DLL из папки плагинов.
3. В r2modman выбери Settings → Import local mod и укажи `DoormanMod-1.1.7.zip`. Запусти игру через Start modded.
4. В настройках управления проверь клавишу Extra Skill 1. На ней находится Baroness.

Для прототипа хватает одной `DoormanMod.dll` и зависимостей из `manifest.json`. Модель Commando и временные визуалы способностей используются автоматически.

## Сборка исходников

Для Visual Studio положи `ExtraSkillSlots.dll` из активного профиля r2modman в `HenryMod/lib/` или передай её путь как свойство MSBuild.

```powershell
dotnet build HenryMod/DoormanMod.csproj -c Release "-p:ExtraSkillSlotsPath=C:\path\to\ExtraSkillSlots.dll"
```

Сборка копирует DLL в `Build/plugins/`. В этой папке также могут лежать файлы старого шаблона Henry. Для локальной установки упакуй только актуальные `manifest.json`, `README.md`, `icon.png` и `plugins/DoormanMod.dll`.

## Замена моделей

Опциональный бандл должен называться `doormanbundle` и лежать по пути `AssetBundles/doormanbundle` рядом с DLL. Если Unity соберёт его в `HenryUnityProject/AssetBundles/`, MSBuild скопирует его при следующей сборке. Префабы способностей содержат только визуальную часть. Сетевые компоненты, коллизии и урон настраиваются в моде.

| Имя ассета | Назначение |
| --- | --- |
| `mdlDoorman` | Модель персонажа по структуре шаблона Henry. Для вспышки выстрела нужен `MuzzleRight` или `Muzzle` в ChildLocator. |
| `DoormanDisplay` | Отдельная модель для экрана выбора персонажа. |
| `BellVisual`, `CartVisual`, `DoorVisual` | Визуальные префабы колокольчика, тележки и двери. |
| `texDoormanIcon` | Портрет персонажа. |
| `texSHOOTIcon`, `texBELLIcon`, `texDOORIcon`, `texCARTIcon`, `texULTIMATEIcon` | Спрайты способностей. |

## Проверка в игре

- Удерживай основную атаку и проверь непрерывную стрельбу.
- Брось колокольчик под углом вверх. Три красных кольца показывают границу сферы взрыва радиусом 16 м. Проверь попадание по летающему врагу выше и ниже колокольчика. После остановки он должен висеть в воздухе. В кооперативе сначала попроси второго игрока выстрелить в него, потом выстрели сам. Повтори с обоими игроками в роли владельца.
- Используй дверь на открытом месте и рядом со стеной. Проверь направление, положение и исчезновение дверей через 8 секунд. После рывка отойди от двери выхода и войди в неё снова, чтобы вернуться.
- Направь тележку через несколько врагов в стену. Проверь захват, повторный урон и оглушение целей, восприимчивых к нему.
- Попробуй применить Baroness без цели, затем наведи прицел на видимого врага. Он должен исчезнуть на три секунды и получить урон после возвращения. Повтори, прервав состояние персонажа после активации.
